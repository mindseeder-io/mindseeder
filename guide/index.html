mindseeder exports the conclusion you chose as Markdown. Paste it into ChatGPT, Claude or Gemini with one of the requests below and get a finished file: a PDF or Word memo, a PowerPoint deck, a report or one HTML page.

Decision memo, 1 to 2 pages

Conclusion first, then evidence, risks, next steps and sources. PDF, and Word if the service can.

The [Harvest document] below is Markdown exported from mindseeder. Using only its content, write a 1–2 page decision memo and give it to me as a downloadable PDF file. If you can also create a Word (.docx) file, include it.

## Structure (in this order)
1. Title: a one-line title based on the garden name
2. Conclusion: the chosen conclusions from the fruit/flower notes, first, in 2–4 sentences
3. Evidence: the supporting points as a list, each ending with the source note's title in parentheses
4. Risks and counter-evidence: only concerns, objections and uncertainties written in the notes. If there are none, write "No risks recorded in the notes"
5. Next steps: tasks or proposals written in the notes, as action sentences. If there are none, write "No next steps recorded in the notes"
6. Sources: every link in the notes

## Rules
- Copy numbers, dates, units, quotes and proper names character for character. No rounding, unit conversion or paraphrasing of quotes.
- Keep minus signs (−, -), range marks (~, –), percent and currency notation exactly as written in the original.
- Do not add any fact, figure, example or source that is not in the notes. Summary sentences use only what the notes say.
- Content labeled as a made-up example ("fictional", "example", "hypothetical", "가상 예시", "예시") keeps the same label in the memo so it never reads as fact.
- Keep every link from the notes as a clickable link, with the URL unchanged.
- Keep tables as tables.
- If the notes are in Korean, write the memo in Korean, set a Korean font (Noto Sans KR, Nanum Gothic, Pretendard or Malgun Gothic, whichever is available) and embed it in the PDF. After creating the file, check that no Korean text shows as boxes (□) or question marks; if it does, rebuild with another Korean font.
- If it runs over 2 pages, shorten only the evidence list; keep the conclusion, risks, next steps and sources intact.

Finish with one line confirming that you compared the output against the original and no number, quote or link was changed.

## Page structure
1. Header: a title based on the garden name
2. Conclusion: the chosen conclusions from the fruit/flower notes, in a highlighted box
3. Evidence: a subheading and body per note, with the source note's title next to each subheading
4. Risks and counter-evidence, next steps: only what the notes say. If a section has nothing, show "Nothing recorded in the notes"

## Technical requirements
- Put all CSS in a `<style>` block. Use no external scripts, tracking code or external images.
- Include `<meta charset="utf-8">`, a responsive layout that reads well at phone width, and print styles (@media print).
- If the notes are in Korean, use `<html lang="ko">` and the font stack `Pretendard, "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif` so Korean renders without loading external fonts. Otherwise use `<html lang="en">` and a system font stack.
- Keep text readable in dark mode (prefers-color-scheme).

- Keep every link from the notes as an `<a href>` link, with the URL unchanged.
- Keep tables as `<table>`.

4Check the file before you send it

  • Open the file and compare every number, quote and link with your notes. The requests ask the AI to report this, but read it yourself.
  • Korean text in a generated PDF can show as boxes when the service has no Korean font. Ask it to use Noto Sans KR or Nanum Gothic, or export to Google Docs first and download the PDF from there.
  • A PowerPoint file does not carry its fonts. In desktop PowerPoint turn on File, Options, Save, Embed fonts in the file before you share it.
  • Content marked as a fictional example stays marked; keep it that way in anything you send.
